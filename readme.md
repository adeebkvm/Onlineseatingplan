# Examination Seating Plan & Memo Generator

A web application built with Streamlit to automatically generate examination seating plans and class-wise attendance memos in Excel format.

## Features
* **Seating Plan Generation**: Intelligent room allocation based on student counts, capacities, and stream mixing.
* **Class Memos**: Generates attendance memos with present and absent student breakdowns.
* **Web Upload & Download**: Easily upload `input_data.xlsx` and `Rooms.xlsx` and download results instantly.
